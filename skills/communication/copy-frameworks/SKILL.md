# Copy Frameworks

Write emails that get responses using campaign-tested copy frameworks.

## Frameworks Available

### SPARK (recommended for cold/warm outreach)
- **S**ituation — establish context quickly
- **P**roblem — name the pain or gap
- **A**ngle — your unique take or hook
- **R**elevance — why this matters to them specifically
- **K**ick — clear, low-friction CTA

### PAS (Problem-Agitate-Solution)
Best for: re-engagement, when the pain is well-understood
- Name the problem → amplify why it matters → offer the solution

### AIDA (Attention-Interest-Desire-Action)
Best for: introducing something new
- Hook attention → build interest → create desire → drive action

### The Nudge
Best for: follow-ups to non-responders
- Acknowledge the silence → restate value in one sentence → make an even easier ask

## Step 1 — Pick the Right Framework

Based on `$ARGUMENTS`:
- First contact or warm lead? → SPARK
- Following up on silence? → Nudge
- Re-engagement after "later"? → PAS
- Introducing new offer? → AIDA

## Step 2 — Write the Email

Apply the framework. Rules:
- Subject line: specific, not clever. Under 8 words.
- Opening line: no "I hope this finds you well." Start with them, not you.
- Body: 3-5 sentences max
- CTA: one ask, low friction ("Does this still make sense?" beats "Schedule a call")
- No attachments in first touch
